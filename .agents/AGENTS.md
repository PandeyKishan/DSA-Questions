# Agent Rules for DSA Questions

## Formatting for DSA_APPROACHES.md and DSA_PATTERNS.md
Always follow the correct formatting for everything. Keep it the same as the previous state, unless the user explicitly mentions any new formatting or look changes.

Specifically:
- In `DSA_APPROACHES.md`, questions must be added in the format:
  ```markdown
  <q_num>. **<Question Title>:**
      - **Approach:** <Approach details>
  ```
  Followed by a blank line before the next entry. Do not write the approach on a single line directly after the number.
- In `DSA_PATTERNS.md`, do not append new questions as separate bullet points at the bottom of a pattern section. Instead, group them inline under their respective sub-pattern headers (such as `- **Variable Window:**` or `- **Fixed Window:**`) as comma-separated lists.
