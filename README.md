# DSA Questions & Resources

Welcome to my DSA practice repository. This workspace contains both my solved problems and curated study materials.

## 📂 Project Structure

### 🧠 Practice Problems
The core of this repository is organized by data structure and algorithm topics:
- **Arrays/**: Solutions categorized by difficulty (Easy, Medium, Hard).
- **Basics and Maths/**: Fundamental concepts and mathematical problems.
- **Hashing/**: Practice with hash maps and frequency counting.
- **Recursion/**: Recursive implementations for common problems.
- **Sorting/**: Classic sorting algorithm implementations.

### 📚 Study Resources
All external learning materials are located in the `Resources/` folder, organized as follows:

- **`Resources/Questions`**: curated DSA problem sets and revision guides (e.g., 75 DSA Questions, Tier 3 Sheet).
- **`Resources/Cheatsheets`**: Quick reference guides for Arrays, DP, Strings, and Space Complexity.
- **`Resources/Roadmaps`**: Structured learning paths for DSA, AI/ML, and LLD.
- **`Resources/Interview-Prep`**: Strategy guides, System Design materials, and company-specific preparation.
- **`Resources/Career`**: Job search tools, referral templates, LinkedIn optimization, and HR contact lists.

## 🚀 How to Use
1. **To Solve Problems**: Navigate to the respective topic folder (e.g., `Arrays/Medium`) to find specific problem implementations.
2. **To Study**: Check the `Resources/` directory for roadmaps or cheatsheets to guide your learning or prepare for interviews.
